Flagship project

RbcTcsWorld E-Commerce Suite

An Amazon-inspired online store built to be tested: checkout with a validated delivery address, Stripe payments, order e-mails, a password reset by single-use e-mailed link, guest checkout and an address book, size and colour variants, a faceted filter panel with counts, flash deals with a countdown, "customers also bought", invoice PDFs, optional two-factor sign-in by e-mailed code, a saved-card wallet that keeps tokens only, a full store back office with eight printable reports, multi-warehouse inventory, and an append-only, hash-chained audit trail inspired by 21 CFR Part 11 / ALCOA+. The application is the test object; the work is the test system around it. Every push runs 18 quality gates, and a failing gate blocks the build.
